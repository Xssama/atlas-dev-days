# Atlas Dev Days

Site vitrine de la première édition fictive des Atlas Dev Days, une conférence de deux jours consacrée au développement web au Maroc.

## Fonctionnalités

- Présentation de l'événement et chiffres clés.
- Programme des deux journées.
- Présentation des six intervenants.
- Formulaire d'inscription avec validation native HTML.
- Navigation entre quatre pages.
- Mise en page responsive avec Flexbox.

## Technologies

- HTML5
- CSS3
- Figma
- Git et GitHub
- GitHub Pages
